\# FlowLedger



FlowLedger is a web-based financial request and approval management system.



\## Tech Stack



\### Frontend

\- React

\- Vite

\- Axios

\- React Router



\### Backend

\- Node.js

\- Express.js

\- MongoDB

\- Mongoose



\## Project Structure



\- `frontend/` — React frontend

\- `backend/` — Express backend

\- `docs/` — Project documentation
